# ДЗ #4: Налаштування VS Code та npm

У корені репозиторію ініціалізовано npm-проєкт (`package.json`) і налаштовано Prettier (`.prettierrc`, `.prettierignore`). Також додано `live-server` для локальної розробки та рекомендовані розширення VS Code в `.vscode/extensions.json`. Код ДЗ #1–3 відформатовано.

Скрипти (запускати з кореня репо після `npm install`):

- `npm run format` — відформатувати всі файли;
- `npm run format:check` — перевірити форматування;
- `npm run info` — вивести назву й версію проєкту;
- `npm run dev` — запустити live-server.
