# ДЗ #6: Стилі для твого лендінгу

Лендінг BookNook із ДЗ #5 стилізовано зовнішнім `style.css`: box model, контейнер, типографіка, таблиця, форма, темний footer і кнопка з плавним hover.

Палітра: акцент `#b45309` (hover `#78350f`), текст `#292524`, фон `#fffbeb`, світла поверхня `#fef3c7`. Шрифт: Nunito з Google Fonts (запасний — Arial, sans-serif).

Як відкрити: відкрийте `hw-06/index.html` у браузері або перейдіть на GitHub Pages: https://kustymenko.github.io/my-web-course/hw-06/
