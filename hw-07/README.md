# ДЗ #7: Верстка з Figma — position та absolute

Каталог товарів Shopy за макетом Free eCommerce Product Cards: три різні картки (зі знижкою, з бейджем NEW і спрощена з кнопкою «додати»), що повторюються у flex-сітці з `flex-wrap`. Бейджі, серце «в обране», вибір кольорів і кругла кнопка позиціонуються через `position: absolute` усередині картки з `position: relative`. Додано бонуси: sticky-шапка, кнопка «нагору» (`fixed`), hover-ефекти та одна колонка на мобільному.

Третя картка (за макетом Style 4) серця не має: замість нього є кругла кнопка «додати».

Розміри, кольори, шрифт Roboto та склад карток (Style 2 і Style 4) звірено з макетом у Figma.
