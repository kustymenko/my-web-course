# ДЗ #8: Верстка лендінгу з Figma (treine.me)

Лендінг treine.me за макетом Layout to study HTML & CSS: шапка з логотипом і меню, hero з двома колонками (текст, кнопка «Start now» з іконкою WhatsApp | ілюстрація) та футер. Кольори й шрифти (Mulish, Open Sans, Inter, DM Sans) винесено в CSS-змінні й Google Fonts, розкладка зроблена на Flexbox. Додано бонуси: точковий декор у кутку, hover-ефекти та адаптив до 768px.

Як відкрити: відкрийте `hw-08/index.html` у браузері або перейдіть на GitHub Pages: https://kustymenko.github.io/my-web-course/hw-08/
