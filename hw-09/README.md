# ДЗ #9: Вечір у кафе — рахунок, чайові та паролі

У `script.js` реалізовано `splitBill` (поділ рахунку з чайовими та валідацією), `passwordStrength` (оцінка надійності пароля з порадами), `generatePassword` (генератор з гарантією кожного обраного типу символів) і бонусну `splitBillUneven`. Результати прикладів з умови виводяться через `console.log`.

Як запустити: `node hw-09/script.js` у терміналі або відкрийте `hw-09/index.html` у браузері та перегляньте консоль (F12).
