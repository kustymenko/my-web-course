# ДЗ #10: ASCII-майстерня і таємні послання

У `script.js` реалізовано фігури з символів (`pyramid`, `christmasTree` на основі `pyramid`, `chessboard`) та шифр Цезаря (`encrypt`, `decrypt`, `bruteForce`). Як бонус шифр працює і з українською абеткою з 33 літер, а латиниця працює далі.

Як запустити: `node hw-10/script.js` у терміналі або відкрийте `hw-10/index.html` у браузері та перегляньте консоль (F12).
