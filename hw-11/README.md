# ДЗ #11: Кіноаналітика — вижми все з датасету

У `script.js` є датасет із 17 фільмів і 7 функцій аналітики (`topRated`, `releasedAfter`, `boxOfficeByGenre`, `directorRating`, `bestYear`, `searchByTitle`, `recommend`), написаних лише на методах масивів (`map`, `filter`, `reduce`, `sort`, `slice`), без `for` і `while`. Як бонус додано `top3DramasOf2010s` — один ланцюжок без проміжних змінних; наприкінці виводиться «звіт для керівника».

Як запустити: `node hw-11/script.js` у терміналі або відкрийте `hw-11/index.html` у браузері та перегляньте консоль (F12).
