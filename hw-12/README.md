# ДЗ #12: Модалка та dropdown для твого продукту

До лендінгу BookNook із ДЗ #6 додано секцію «Моя полиця» з картками книг. Кнопка «Детальніше» відкриває модальне вікно (закриття хрестиком, кліком по затемненому фону або Escape; сторінка не прокручується, анімація лише на CSS), а три dropdown (категорія, статус, сортування) фільтрують і сортують книги. Бонус: у модалці є фокус-пастка, а після закриття фокус повертається на кнопку-відкривач.

Як відкрити: відкрийте `hw-12/index.html` у браузері або перейдіть на GitHub Pages: https://kustymenko.github.io/my-web-course/hw-12/
