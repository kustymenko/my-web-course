# ДЗ #13: Жива форма — валідація та localStorage

Форма підписки з лендінгу BookNook отримала валідацію без вбудованих підказок браузера (`novalidate`): точні тексти помилок, червона й зелена рамки через CSS-класи, перевірка на `blur` та на кожен символ (`input`). Після успішної відправки дані (ім'я, email, вік, дата; без пароля) зберігаються в `localStorage`, з'являється повідомлення на 3 секунди, а блок «Наші підписники» оновлюється без перезавантаження. Бонус: індикатор сили пароля з прогрес-баром.
