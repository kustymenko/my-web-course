# ДЗ #14: Мій каталог

Застосунок «Мій каталог книг» у стилі BookNook: додавання книг (кнопкою і Enter), перемикання статусу «прочитано» кліком по чекбоксу чи назві, редагування подвійним кліком (Enter, blur, Escape; порожня назва видаляє книгу), видалення, фільтри Всі / Непрочитані / Прочитані, лічильник з відмінюванням («1 книга / 2 книги / 5 книг») та кнопка «Очистити прочитані». Масив `items` є джерелом правди, після кожної дії виконується `render()` і дані зберігаються в `localStorage`, тож F5 відновлює все зі статусами. Бонус: категорії з кольоровими мітками та фільтр за категорією.

Як відкрити: відкрийте `hw-14/index.html` у браузері або перейдіть на GitHub Pages: https://kustymenko.github.io/my-web-course/hw-14/
